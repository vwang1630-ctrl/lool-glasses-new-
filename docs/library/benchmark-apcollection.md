- 名人背书：Jinkee Pacquiao 晒 Iceberg Chair

## 二、经营层（警示 ❌）

- 财务（NBB 比利时国家银行 2023 财报，2024-07-24 提交）：**毛利 €324,616**，营业额未公布（估 ~€45-55 万），**5.8 FTE**，成立 2015-05 仍为 Small
- 模式：限量 25-100 件 + 3 个月交期 + 询价制 + 纯手作 → **产能锁死营收**，媒体声量世界级但接单能力跟不上
- 人均年毛利 ~€5.6 万：养活 5-6 人的作坊，非可规模化生意
- 数字层裸奔：无价格、无下单流、订阅表单损坏、collection 停更 2021、零 SEO/GEO/工程证据
