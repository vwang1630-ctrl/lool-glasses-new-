# 图片生产流水线 · 四员工对账 V1.0（2026-10-06 吸收）

> 来源：站主投喂——"每来一个新品"的四员工 AI 图片生产流水线（视觉分析师→卖点转译师→生图美工→合规审核，飞书 Base 逐行看板）。
> 总判定：**三采一拒**——1/2/4 号员工全盘适配本店缺口；3 号生图美工=战略拒绝（AI 产品图=自毁 ai-vs-real 护城河，红线）。

---

## 1号 · 视觉分析师（✅采纳）

8 维度拆对标主图：构图/布局/色彩/方案/卖点排布/光影/信息层级 → 输出"必须借鉴"+"可差异化"+"禁止"三清单。
**本店用法**：对标对象=luxarts 系爆款图+类目 Top PDP。产出挂发布包，每张社媒图/PDP 主图改版前先出拆解单。
**借鉴三清单示例（猫头鹰首发已隐含，正式化）**：
- 必须借鉴：白底/场景大产品主体、真人比例入镜、一图一卖点
- 可差异化：不做渲染感（我们全实拍=差异化本身）、不做低价 plush 质感
- 禁止：竞品 App 截图、未证实认证/排名、"100%"字样（与 rb2/rb13 同构 ✓）

## 2号 · 卖点转译师（✅采纳——本店最缺的一环）

规则：功能描述→用户收益；参数罗列→使用场景；每图 2-3 个短语，**每个 ≤7 词**；主图/副图卖点排优先级。
**Mofu 本地化示例（≤7 词/条）**：

| 参数/中文卖点 | 转译（用户收益） | 优先级 |
|---|---|---|
| 42cm firm raised seat, no collapse | Sits firm. You sink. | P0 |
| A hug that never leaves（核心叙事） | The hug that never leaves | P0 |
| 38kg 实重+钢架 | 38 kg of real furniture | P1 |
| rated 200 kg | Rated 200 kg. Tested, not guessed. | P1 |
| 三色（Pearl/Emerald/Tatami） | Three colours. One cat. | P2 |
| W1200 紧凑形制 | Fits where sofas don't | P2 |

**用途**：Carousel/发布包每图的 caption 首行+画面字幕直接用短语；发布包臂别行旁加"本图卖点短语"字段。

## 3号 · 生图美工（❌战略拒绝——附一个边界例外）

- 产品图/场景图/主图 AI 生成 = **红线**（ai-vs-real 护城河自毁；LuxArts 生态=前车之鉴）
- **边界例外**：ai-room-preview（房间预览）是既有功能——AI 只用于"放進你家的预览"，产品本身永远实拍。此边界不动。

## 4号 · 合规审核（✅采纳——补图片级闸门空白）

我们文字闸门齐全（rb1-14），**图片级逐张审核是空白**。采纳其 7 大项+AI 缺陷检测，本地化：

| 检查项 | 本店要点 |
|---|---|
| 主图规范 | 首图产品主体清晰（实拍 ✓ 天然过） |
| 商标/版权 | 无别家 logo/未授权 IP（动物造型远离迪士尼式形象） |
| 虚假宣传 | 画面主张与口径一致（200kg/无真空/无纯手工） |
| **AI 缺陷检测** | **不适用（全实拍）**——但反向价值：实拍图里的工坊杂乱/穿帮入镜检查（S6 工坊实拍防泄密） |
| 材质一致性 | 图与 description 材质主张一致（缎面 vs boucle 不混） |
| 尺寸表达 | 比例真实（不缩放夸大） |
| 人物授权 | 出镜者同意（工坊师傅/家人） |

产出：每图 通过/需修改/不通过+风险等级。**挂发布包流程：图先过此审，再进包。**
