## 吸收纪律

1. 外部框架先过三问：他的客户是谁？他的证据是什么？他的行业边界在哪？
2. 每条吸收带"采纳/改造/拒收"三态标注 + 本店实证引用
3. 与活库既有机制冲突时，活库纪律优先（例：他砍社媒 vs 我们 IG 实证流量王——拒）
4. 工具类外部能力一律过 tool-radar 两道门（解决哪张工单/服务哪个阶段的我们）
