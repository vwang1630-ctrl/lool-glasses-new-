## G. 首周执行流（周日晚穿透测试 → 周一开闸）

**周日晚穿透测试（5 环，全通才开闸）**：
发一条自测内容 → 自评评论问价 → 自测 DM 一条 → 点 UTM → GSC/consult_events 核对归因。
自测打标不计成绩（既有纪律）。断任何一环=开闸前修。

**首周成功定义（采纳"首个 T1 样本"）**：
**1 帖发布 → 1 真实曝光 → 1 互动/问价 → 1 条归因记录**。跑通一个样本，诚实边界 1/3 即从 L0 升 T1。
≠ 爆款 ≠ 出单 ≠ 播放 5000（判例 012）。

**冷启动中间指标（防连续判定失败，只记不判）**：触达→回复率 / 曝光数 / 收藏与主页访问。
