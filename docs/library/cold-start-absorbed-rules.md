# 冷启动外部框架 · 吸收细则归档（2026-10-04）

> 来源：站主提供的第三方 DTC 冷启动课程总结（通用独立站框架）。
> ⚠️ 归属修正（2026-10-04）：本文件 IG 相关细则与 `ig-internals-study.md`（机制研究块，2026-10-02）重叠——**IG 机制以 internals-study 为准**，本文件只记增量执行细则。
> 状态：**只吸收执行细则，不换仪表盘**——其基准（复购率/完播率/≤2kg 选品）为大众跑量品设定，
> 不适用于本站高客单收藏品模型（$9,900 / 45kg+ / 决策周期月级 / LTV=口碑+项目单）。
> 数字一律标 T4：可用作脑内基线，不进台账、不外发、不做承诺。

## 已吸收（进执行 SOP）

### 1. 社媒发布 2 小时互动率判定（进发布包工作流）
- 发布后看**前 2 小时**互动率 =（点赞+评论+收藏）÷ 播放量
- **<1%**：标签不对或开头没抓住 → 换角度重发，不追发
- **>3%**：算法识别对人群 → 追发同类型内容
- 冷启动本质：不是让所有人看到，是让算法给内容打对兴趣标签，先赢前 100 个精准用户

### 2. Reddit 渗透 SOP（W3 从业者 AMA 前置动作）
- 找帖：`site:reddit.com [品类关键词]`，优先 **24h 内新帖**
- 意图信号词：`recommendation` / `looking for` / `anyone using`
- 节奏：前两周只答题不提产品；被问推荐时再自然带出
- 叙事框架：**"I built this for myself / we manufacture these"**（真实从业者身份，严禁假买家——站主红线）
- 一条精准回答 > 100 条泛内容

### 3. YouTube/Pinterest 搜索入口规则（W1 研究块原料，建块时并入）
- YouTube：关键词进**标题前 5 个词**、描述第一句、视频**前 30 秒口播说出**；新频道瞄准月搜索 300–5000、低竞争词
- Pinterest：本质图片搜索引擎——产品图做成场景灵感图，标题描述用搜索词；收藏后长期出现在的搜索里
- 与本站视频拍摄要求（口播实体共现台词卡）天然同构

## 明确不吸收

- 复购率/LTV:CAC/完播率等基准 KPI——品类不适用
- "邮件捕获弹窗"——站主令暂缓（2026-10-04）；未来做时钩子用样品卡/AR 图包，不用折扣码
- 无出处的 ROI/降本百分比——T4，不引用
