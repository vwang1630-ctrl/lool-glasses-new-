## 四、站主数据收集工作流（每周日 15 分钟）

### Step 1：Pinterest 后台（3 分钟）
打开 pinterest.com → 分析工具 → 概览 → 过去 7 天 → 截图

### Step 2：Instagram Insights（3 分钟）
打开 IG → 专业账号 → Insights → 按「内容」和「受众」分别截图

### Step 3：Facebook Page（2 分钟）
business.facebook.com → Insights → 概览 → 截图

### Step 4：竞品速览（5 分钟）
IG 搜索 #fauxfurcouch → 看排名前 5 的帖子 → 截图
搜索 "gorilla sofa" → 看有没有新竞品出现

### Step 5：Trends 速查（2 分钟）
Pinterest Trends → 搜 "gorilla sofa" → 看趋势方向 → 截图

### Step 6：把所有截图打字发给我 → 我当场分析

## 五、我收到数据后的处理流程

```
你发截图/数字
    ↓
我当场分析（1 分钟内回复）：
    · 曝光涨了还是跌了？
    · 哪条钩子最有效？
    · 有没有新的竞品动作？
    · 下周要不要调整？
    ↓
每周一正式分析（GSC 数据 + 你的收件箱数据合并）
    ↓
产出一页分析报告：
    · 本周数据 vs 上周数据 vs 基线
    · 哪条内容最有效 → 下批加码
    · 哪条内容无效 → 下批停用
    · 新发现的竞品动作 → 是否需要回应
    ↓
下周一例会：你拍板下一步
```
