# FUZZ SOFA 视觉风格规范 v1.0（2026-10-04）

> 一句话：**硬世界里的软雕塑**。品牌句 "brutal outside, tender inside" 的视觉直译。
> 对位：AP Collection 的糖果毛绒风是它的赛道（高饱和/可爱/堆满），我们走反差极简（硬环境+柔软产品）。

## 三系列（IG 九宫格轮换）

1. **画廊系列**：素水泥/画廊白墙，产品独占，博物馆射灯，大量留白，低角度仰拍（纪念碑感）
2. **工坊系列**：焊花/模具/手/卷尺读数，纪录片原声质感，不修饰瑕疵——工程证据系列（我方独有）
3. **客户家系列**：Try in Your Room 渲染 + 真实客厅自然光

## 硬规矩

| 项 | 执行 |
|---|---|
| 调色 | 低饱和暖中性、对比略高；禁糖果色/奶油柔焦/过度磨皮 |
| 构图 | 产品孤独主角+留白；低角度仰拍；真人入镜反衬体量 |
| 色板 | 炭黑/骨白/原木 + ≤1 点缀色；画面无第三方 logo、无花哨陈设 |
| 光线 | 雕塑镜头硬质定向光；生活场景自然窗光 |
| 反面清单 | 糖果毛绒堆满、样板间 stock 感、可爱道具、滤镜满屏——废片 |

## 依据

- 品牌句与产品哲学的视觉直译；对 AP 糖果风的赛道区隔（其对标自身验证过"混凝土别墅+毛绒镜"的反差路线有效）
- 适用范围：IG 九宫格、媒体资料包、产品页图、投稿配图、视频成片与剧照
