## 7. 流量结构拆解（SEMrush + Similarweb 2026.08）

### 7.1 SEO：量大但极度偏科品牌词

| 指标                      | 数据   |
| ------------------------- | ------ |
| 月访问                    | 6.3M   |
| 全球排名                  | 9,099  |
| 美国排名                  | 2,134  |
| 有机关键词（Google前20）  | 54,743 |
| Similarweb 实际有效关键词 | 9,500  |

**Top 3 关键词全为品牌词：**

| 关键词          | 搜索量 | 流量占比 |
| --------------- | ------ | -------- |
| zeelool         | 246K   | 52.55%   |
| zeelol（拼错）  | 40.5K  | 8.65%    |
| zeelool glasses | 27.1K  | 5.79%    |

**翻译**：52% 流量来自搜自己品牌名。非品牌词 `best reading glasses`、`affordable progressive glasses` 根本没吃到。54K 关键词大部分是 SKU 长尾页， Similarweb 实际有效只有 9.5K。

**流量模型**：社媒种草 → 品牌搜索 → 进站。SEO 本身不强，是品牌搜索强。

**付费流量依赖**：Display 1st / Paid Search 2nd / Direct 3rd — 靠买量兜底。

### 7.2 GEO（AI 搜索）：几乎为零

| 指标                | 数据   |
| ------------------- | ------ |
| ChatGPT 引流        | 16K/月 |
| 占 6.3M 比例        | 0.25%  |
| AI Overviews 可见性 | 搜不到 |

**原因**：内容全是 SKU 参数页，没有 `What is PD`、`How to choose reading glasses for 45+` 这种会被 ChatGPT 引用的深度教育内容。Similarweb 已提示 `Is Your Website Ready for AI Search?` — 答案是没有。

### 7.3 社媒：真正的主战场

| 平台        | 数据                                                 |
| ----------- | ---------------------------------------------------- |
| TikTok      | 920K 粉丝，百万播放视频多个                          |
| Instagram   | 时尚眼镜 photos + accessories matching               |
| TikTok 打法 | 找 famous KOLs fashion eyewear try-on shows          |
| 欧洲        | 专门招人管理 IG/TikTok/FB/Pinterest/YouTube 内容策略 |

**用户画像验证（Similarweb）：**

| 指标      | 数据          | 含义               |
| --------- | ------------- | ------------------ |
| 性别      | Female 73.27% | 逛街型女性         |
| 跳出率    | 47.4%         | 进站后愿意逛       |
| 页次/访问 | 6.11          | 深度浏览           |
| 平均时长  | 4:02          | 不是 bounce-and-go |

**所以 ZEELOOL = 社媒驱动品牌搜索，品牌搜索驱动 SEO。**

路径：TikTok KOL试戴 → 用户搜 `zeelool` → 进站 → 6.3M 访问。不是靠 `best glasses` 自然排名。

### 7.4 loollook 攻击面

| 维度           | ZEELOOL 现状                     | loollook 打法                                                   |
| -------------- | -------------------------------- | --------------------------------------------------------------- |
| **非品牌 SEO** | 空白（不写深度内容）             | 5簇关键词矩阵直接抢，`ageless-eyewear` 全市场无人占             |
| **GEO**        | 16K = 0.25%，AI Overviews 搜不到 | 结构化 FAQ + measure-pd + prescription-guide，AI 最爱引用的格式 |
| **社媒人群**   | 73%女性，18-35颜值驱动           | 45-60信任驱动，TikTok 录屏 `30s真PD测量` 碾压 `fashion try-on`  |

**一句话**：它走「颜值社媒→品牌搜索」，你走「真工具信任→非品牌长尾SEO+GEO」。两条路不撞车，但你能截它的胡。

### 7.5 首篇 blog 调整（基于流量结构）

**不写** `ZEELOOL Review`（那是品牌词，截不到量）。

**写** `Best Reading Glasses for 45-Year-Old Professionals (No Senior Look) - 2026 Guide`：

- 里面对比 `Zeelool AR vs lool True Try-On`
- 既是 SEO（非品牌长尾词）
- 又是 GEO（结构化内容，AI可引用）
- 还能当 TikTok 脚本（30s 录屏对比）
- 关键词：`reading glasses for 45+`, `ageless reading glasses`, `reading glasses that don't make you look old`
- 画像：画像4（老花羞耻 10%但价值最高）— 全市场空白，loollook独占
