# lool 视觉风格规范 V1.0

> 一句话：**清晰视界，不被定义**。45-60 代际的自信与品味。
> 去老年化叙事——我们的人看起来精神好、有品味，不"年轻"。

## 三系列（IG/Pinterest 轮换）

1. **产品美学系列**：纯色背景/生活场景，产品独占，自然光或柔光，展现镜框细节（材质/颜色/工艺）
2. **功能展示系列**：虚拟试戴 demo、PD 测量教程、渐进镜片科普——屏幕录制+字卡叠加
3. **生活方式系列**：真实 45-60 代际人物阅读/工作/社交场景，传递"ageless design"理念

## 硬规矩

| 项       | 执行                                                       |
| -------- | ---------------------------------------------------------- |
| 调色     | 温暖中性色调，对比适中；禁过度磨皮/美颜滤镜/糖果色         |
| 构图     | 人物自信从容+产品清晰；避免仰拍显距离感                    |
| 色板     | 温暖中性（米白/灰/深蓝/铜色）+ 镜框本色；画面无第三方 logo |
| 光线     | 产品图柔和均匀光；生活场景自然窗光/暖光                    |
| 人物     | 真实 45-60 代际，精神饱满、自信从容                        |
| 反面清单 | 老年标签暗示、过度美颜、stock photo 感、可爱道具堆砌——废片 |

## 品牌视觉元素

- **品牌名**：小写 lool（不是 LOOL 或 Lool）
- **Signature**："See clearly, agelessly." / "清晰视界，不被定义。"
- **产品镜头**：镜框特写+镜片反光质感+佩戴效果
- **功能镜头**：屏幕录制+字卡（虚拟试戴/PD 测量）

## 禁用视觉元素

- ❌ 任何暗示"老年"的视觉（放大镜、白发特写、驼背、拐杖）
- ❌ 过度美颜/磨皮滤镜
- ❌ "Before/After" 对比（暗示需要"修复"）
- ❌ 医疗感/诊所感的视觉
