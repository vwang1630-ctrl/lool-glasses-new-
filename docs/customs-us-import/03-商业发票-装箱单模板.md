# 03 · 每票随附单证模板（商业发票 + 装箱单）

> 每一票货放进箱内的两张纸。模板里 [方括号] 换成当票信息。
> **核心纪律：货值 = 客户实付的商品价（真实申报），运费单列一行。**
> 美国关税按商品货值计税，运费拆开列不冤枉多缴，混在一起反而说不清。

---

## 一、Commercial Invoice（商业发票）

```
                          COMMERCIAL INVOICE
Invoice No.: [FZ-2026-0001]              Date: [YYYY-MM-DD]
Incoterms: DDP [目的地城市, US]           Currency: USD

SELLER / EXPORTER:
  [公司英文全名]  (Chinese company, Importer of Record for US customs)
  [中国地址]     Tel/WeChat: [xxx]

IMPORTER OF RECORD:
  Same as seller — Chinese company
  EIN: [XX-XXXXXXX]     CBP importer no. (after first 5106): [____]

CONSIGNEE / ULTIMATE CONSIGNEE (US customer):
  Name: [客户名]    Address: [美国地址, ZIP]
  Tel: [客户电话]

| No. | Description                    | HS Code    | Origin | Qty | Unit Value | Total  |
|-----|--------------------------------|------------|--------|-----|------------|--------|
| 1   | Noctua Owl Armchair, upholstered seat,  | 9401.61.00 | CN     | 1   | 4,800.00   | 4,800.00 |
|     | wooden frame, made-to-order, model NOC-A |           |        |     |            |          |

Goods total:                                          USD 4,800.00
Ocean freight & insurance (billed separately):        USD [xxx] (not for customs value)
Total invoice value (DDP):                            USD [ goods + freight ]

Country of origin: CHINA
HS classification: 9401.61.00 (upholstered seats with wooden frames)
Purpose: SALE — made-to-order consumer furniture, no trademark restrictions

We declare that the information above is true and correct.
Signature: ____________________  Name/Title: [法人, Legal Representative]  Company chop
```

**要点：**
- HS 归类按产品实际结构：木框软垫座椅 9401.61.00；钢/金属框软垫 9401.71.00（基础税率更低，
  让报关行按箱体框架材质定，一锤定音后写进每票发票，别每票换归类）。
- 品名写清楚「upholstered seat + frame 材质 + made-to-order」，美国海关按字面归类，写清楚少查验。
- 发票签名处**盖公章 + 法人签字**（复印/扫描各留一份）。

## 三、每票发货 checklist（发给货代前自查）

- [ ] 商业发票：货值真实、运费单列、盖公章签字
- [ ] 装箱单：箱号/尺寸/毛重与实物一致
- [ ] 客户全名 + 完整美国地址 + 电话（ISF 和末端派送都要）
- [ ] POA/bond 状态有效（第一票前确认货代已交 5106）
- [ ] 报关行承诺回传：税单（duty statement）+ 入境编号（entry number）——**每票都要，存档**

> 税单和 entry number 是以后退货追税（美国关税复出口 1 年内可申请退回）和审计的唯一凭证，
> 一次都不能少。
